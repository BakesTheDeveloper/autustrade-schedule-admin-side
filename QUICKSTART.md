# Quick Start Guide

## Start the Server (Required!)

Open a terminal in this directory and run:

```bash
npm start
```

Keep this terminal window open while using the application.

## Access the Application

Once the server is running:

### 📅 Client Booking Page
Open in your browser: **http://localhost:3000/client/index.html**

### 🔧 Admin Dashboard
Open in your browser: **http://localhost:3000/admin/index.html**

## Test the System

1. **Book an appointment** on the client page
2. **Click the Refresh button** (🔄) on the admin dashboard
3. **See your appointment appear** in the admin table!

## Important Notes

- ✅ The server MUST be running for appointments to sync
- ✅ Always access via `http://localhost:3000` (not by opening files directly)
- ✅ Click "Refresh" on admin side to see new appointments
- ✅ Appointments are saved in `appointments.json`

## Stop the Server

Press `Ctrl + C` in the terminal where the server is running.
